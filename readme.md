# Banking System Console Project

## About the Project
This is a console-based Banking System developed
using Core Java.

## Technologies Used
- Java
- OOP Concepts
- Collections Framework
- Scanner Class
- VS Code

## Features
1. Create Bank Account
2. Login Authentication
3. Deposit Money
4. Withdraw Money
5. Check Account Balance
6. Transfer Money
7. Transaction History
8. Logout

## How to Run

1. Install Java JDK.
2. Open the project in VS Code.
3. Open the terminal.
4. Navigate to the src folder.
5. Compile the files:

javac Main.java Bank.java BankAccount.java

6. Run the application:

java Main
